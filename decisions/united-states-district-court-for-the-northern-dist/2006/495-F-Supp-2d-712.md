# Roberts v. Mahoning County

## Majority (PER CURIAM.)

ORDER
PER CURIAM.
Before the Court is the motion to intervene filed by the City of Youngstown pursuant to 18 U.S.C. § 3626(a)(3)(F). (Doc. No. 207). The motion is granted.
Counsel for the City of Youngstown is directed to file the Complaint in Intervention which was attached to the motion, taking care to use the event “Intervenor’s Complaint” when making this electronic filing.
IT IS SO ORDERED.
. Counsel should also be sure to file a clean copy, not the one currently attached to the motion, which contains an automatic header labeling it as Doc. No. 207-3. The ECF system will attached a new header once the new document is filed.
